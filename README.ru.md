# VasilisaBot - Мудрый Telegram-бот с Ollama

VasilisaBot - это асинхронный Telegram-бот, который взаимодействует с Ollama для ответов на вопросы и создания текстовых саммари. Подобно Василисе Премудрой из русских сказок, бот анализирует сообщения, находит их суть и помогает пользователям. Бот поддерживает как личные, так и групповые чаты, сохраняет историю сообщений и корректно обрабатывает иерархию ответов.

## Возможности

- Асинхронная обработка сообщений
- Ответы на вопросы с использованием Ollama
- Создание саммари из истории сообщений
- Выбор различных моделей Ollama (llama2, mistral, gemma, deepseek и др.)
- Настройка пользовательских промптов для чатов
- Работа как в личных, так и в групповых чатах
- Сохранение и восстановление истории сообщений
- Корректная обработка иерархии ответов
- Поддержка редактирования сообщений
- Настройка температуры для разных типов запросов
- Автоматическое сохранение данных
- Простой и интуитивно понятный интерфейс
- Многоязычная поддержка (английский и русский)

## Требования

- Python 3.8+
- [Ollama](https://ollama.ai/) - локальный сервер для запуска LLM-моделей
- Токен Telegram-бота (получается через [@BotFather](https://t.me/BotFather))

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/vasilisabot.git
cd vasilisabot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта и добавьте следующие переменные:
```
TELEGRAM_BOT_TOKEN=ваш_токен_телеграм_бота
LLM_API_URL=http://localhost:11434/api
LLM_MODEL=llama2
BOT_LANGUAGE=RU  # EN для английского, RU для русского
LOG_LEVEL=INFO  # Опционально: DEBUG, INFO, WARNING, ERROR
```

## Запуск

1. Установите и запустите Ollama:
   - Скачайте Ollama с [официального сайта](https://ollama.ai/)
   - Запустите Ollama
   - Загрузите нужные модели с помощью команды `ollama pull llama2` (или другие модели)

2. Запустите бота:
```bash
python bot.py
```

## Автозапуск в WSL

Для настройки автозапуска бота в WSL (Windows Subsystem for Linux) вы можете использовать следующие методы:

> **Важно!** Убедитесь, что у вас запущен только один экземпляр бота. Если вы видите ошибку `Conflict: terminated by other getUpdates request`, это означает, что у вас одновременно запущено несколько экземпляров бота. Перед настройкой автозапуска проверьте и остановите все запущенные экземпляры:
> ```bash
> ps aux | grep python | grep bot.py
> kill <PID>
> ```

### 1. Использование systemd (для WSL2 с поддержкой systemd)

1. Создайте файл службы:

```bash
sudo nano /etc/systemd/system/summarybot.service
```

2. Добавьте следующее содержимое (замените пути на свои):

```
[Unit]
Description=Telegram Summary Bot
After=network.target
StartLimitIntervalSec=0

[Service]
Type=simple
Restart=always
RestartSec=1
User=ВАШ_ПОЛЬЗОВАТЕЛЬ
WorkingDirectory=/путь/к/summarybot
ExecStart=/usr/bin/python3 /путь/к/summarybot/bot.py

[Install]
WantedBy=multi-user.target
```

3. Активируйте и запустите службу:

```bash
sudo systemctl enable summarybot.service
sudo systemctl start summarybot.service
```

4. Проверьте статус:

```bash
sudo systemctl status summarybot.service
```

### 2. Использование скрипта автозапуска WSL

Если вы хотите запускать бота при запуске Windows:

1. Создайте файл `start_bot.sh` в директории проекта:

```bash
#!/bin/bash
cd /путь/к/summarybot
python3 bot.py
```

2. Сделайте его исполняемым:

```bash
chmod +x start_bot.sh
```

3. Создайте пакетный файл Windows `start_bot.bat` в удобном месте на вашем компьютере:

```batch
@echo off
wsl -d НАЗВАНИЕ_ВАШЕГО_ДИСТРИБУТИВА -u ВАШ_ПОЛЬЗОВАТЕЛЬ /путь/к/summarybot/start_bot.sh
```

4. Добавьте этот пакетный файл в автозагрузку Windows:
   - Нажмите Win+R, введите `shell:startup` и нажмите Enter
   - Скопируйте или создайте ярлык для вашего пакетного файла в этой папке

### 3. Использование cron (если systemd недоступен)

1. Откройте crontab для редактирования:

```bash
crontab -e
```

2. Добавьте строку для запуска бота при перезагрузке:

```
@reboot cd /путь/к/summarybot && python3 bot.py >> /путь/к/summarybot/bot.log 2>&1
```

Примечание: Для работы cron в WSL вам может потребоваться запустить службу cron:

```bash
sudo service cron start
sudo service cron enable
```

## Использование

После запуска бота вы можете взаимодействовать с ним через Telegram:

### Общие команды
- `/start` - Начать взаимодействие с ботом
- `/help` - Показать список доступных команд
- `/summarize` - Создать саммари недавних сообщений
- `/hidden_summary` - Создать саммари, видимое только вам
- `/hidden_query` - Задать вопрос, видимый только вам
- `/model` - Выбрать модель Ollama для использования
- `/chatid` - Показать ID текущего чата
- `/factual` - Включить/выключить фактический режим ответов (с пониженной температурой)
- `/config` - Настроить параметры бота
- `/reload` - Перезагрузить модули бота
- Отправьте любое текстовое сообщение, чтобы получить ответ от выбранной модели

### Команды для групповых чатов
- `/prompt` - Настроить пользовательские промпты для текущего чата

### Настройка промптов
Вы можете настроить пользовательские промпты для:
1. Ответов на вопросы - используйте `{question}` для вставки вопроса пользователя
2. Создания саммари - используйте `{text}` для вставки текста для суммаризации

Примеры промптов:
```
# Промпт для ответов
Ты - дружелюбный ассистент в чате. Вопрос: {question}

Ответ:

# Промпт для саммари
Создай краткое и информативное саммари следующей беседы:

{text}

Саммари:
```

### Ответы на сообщения
Бот корректно обрабатывает иерархию ответов. Если вы отвечаете на конкретное сообщение, бот учитывает этот контекст при формулировании своего ответа.

### Настройки конфигурации
Используйте команду `/config` для настройки следующих параметров:
- Температура генерации (для обычных ответов, фактических ответов и саммари)
- Интервал автосохранения данных

## Настройка Ollama

Для работы бота требуется Ollama. Вы можете:

1. Загрузить различные модели с помощью команды `ollama pull`:
   ```bash
   ollama pull llama2
   ollama pull mistral
   ollama pull gemma:2b
   ollama pull deepseek-coder
   ```

2. Создать свои собственные модели с помощью Modelfile:
   ```bash
   ollama create mycustom -f ./Modelfile
   ```

3. Использовать модели с различными параметрами через API

## Структура проекта

Проект был реорганизован в модульную структуру:

```
summarybot/
├── bot.py                  # Основной файл бота
├── config/                 # Настройки конфигурации
│   ├── __init__.py
│   └── settings.py         # Глобальные настройки и константы
├── handlers/               # Обработчики сообщений и команд
│   ├── __init__.py
│   ├── command_handler.py  # Логика обработки команд
│   └── message_handler.py  # Логика обработки сообщений
├── models/                 # Код клиента LLM
│   ├── __init__.py
│   ├── image_handler.py    # Обработка изображений для LLM
│   └── llm_client.py       # Основная функциональность клиента LLM
├── utils/                  # Утилиты
│   ├── __init__.py
│   ├── file_utils.py       # Операции с файлами
│   ├── image_utils.py      # Утилиты обработки изображений
│   ├── language_utils.py   # Утилиты для языка и переводов
│   └── logging_utils.py    # Настройка логирования
├── data/                   # Хранилище данных (создается во время выполнения)
│   └── parquet/            # Хранилище данных Parquet
└── requirements.txt        # Зависимости проекта
```

## Хранение данных

Бот автоматически сохраняет следующие данные:
- История сообщений (в форматах JSON и Parquet)
- Настройки пользовательских промптов
- Выбранные модели для пользователей и чатов
- Настройки температуры генерации
- Общая конфигурация бота

Все данные сохраняются в директории `data/`.
